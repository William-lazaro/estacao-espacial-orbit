# Missão Espacial: Estação Orbit

Projeto de prática do fluxo de desenvolvimento em camadas com Git e GitHub.

## Camadas do ambiente
- **develop**: ambiente de desenvolvimento, onde o código novo é criado.
- **stage**: ambiente de testes e homologação, onde o código é validado.
- **main**: ambiente de produção, com o código final e estável.

## Módulo
- `suporte_vida.py`: monitora oxigênio, pressão e reciclagem de água.
